📝 Resume Editor

How to Edit:

  • Click anywhere on the resume to edit text directly
  • Press Enter to add new lines
  • For permanent changes, edit data.json

How to Print as PDF:

  • Press Ctrl + P (or Cmd + P on Mac)
  • Set Destination to "Save as PDF"
  • Set Margins to "None"
  • Enable "Background graphics"
  • This panel will be hidden in print
